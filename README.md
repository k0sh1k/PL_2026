## Задание 1. Лабиринт

Дана матрица N x M, представляющая из себя лабиринт, где пустой проход — это знак «точка» (`.`), а стена — это знак «плюс» (`+`).

Пример матрицы:

![Пример матрицы лабиринта](images/po_rk1/ex1_rk1.png)

Точка появления — случайный адрес в массиве, по которому можно пройти. Необходимо найти самый короткий путь к выходу. Двигаться разрешается вверх, вниз, влево, вправо. Выходом является пустая ячейка на границе лабиринта. Если точка появления оказалась на границе массива, выходом это место не является.

### Требования

- Вернуть `True` и наименьшее количество шагов для выхода из лабиринта, а также его координаты.
- Если выхода нет, вернуть `False`.

### Критерии оценки

- Оценивается наиболее эффективный вариант решения данной задачи, за наименьшее количество итераций (шагов), совершенных при выходе из лабиринта.
- Критерием оценки является использование массивов (при замене их на другие контейнеры снижается балл).

### Дополнительные баллы

- Размеры матрицы задаются случайным образом.
- Матрица заполняется случайными значениями.
- Выход из лабиринта всегда есть.
- Алгоритм выхода отрабатывает максимально эффективно.

## Задание 2. Поиск пары чисел

Дан упорядоченный массив случайных чисел типа `int` произвольной размерности N, а также число K. Необходимо найти два таких числа в массиве, которые в сумме дают число K.

### Требования

- Вернуть массив с этими элементами.
- Если таких чисел нет, вернуть `-1`.
- Вывести результат на экран.

### Критерии оценки

- Оценивается решение данной задачи с использованием наиболее эффективного алгоритма поиска.
- Критерием оценки является использование ранее пройденных материалов.

### Дополнительные баллы

- Число K определяется случайным образом.
- Программа отрабатывает до тех пор, пока не получит положительный результат.
- На экран выводится количество неудачных попыток.
